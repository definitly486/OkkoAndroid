# Okko Android — WebView-клиент

Небольшой Android Studio-проект на Kotlin, который открывает официальный сайт https://okko.tv/ (и связанные страницы Okko) в приложении. Вход и cookies остаются на стороне сайта; приложение не запрашивает пароль отдельно и не пытается обходить DRM.

## Открыть и собрать
1. Распакуйте ZIP.
2. Откройте папку `OkkoAndroid` в Android Studio.
3. Дождитесь синхронизации Gradle.
4. Запустите конфигурацию `app` на устройстве Android 7.0+ (minSdk 24).

Для APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Важные ограничения
- Это не официальный продукт Okko и не использует закрытые API Okko.
- Сайт может перенаправить на другой домен авторизации/оплаты; внешние ссылки открываются в браузере.
- Возможность просмотра защищённых фильмов зависит от того, поддерживает ли Okko воспроизведение в мобильном браузере и от DRM/сертификатов устройства. WebView не может гарантировать совместимость. Если Okko требует официальное приложение или блокирует мобильный браузер, используйте официальное приложение Okko.
- Приложение не сохраняет логин/пароль в собственных файлах, не перехватывает видеопоток и не обходит Widevine/DRM.
